Obsidian 1.9.14 Desktop (Early access)

No longer broken Desktop: Fixed an issue where pop-out windows would not reopen after quitting the app. Bases: file.hasTag('#tag') is no longer case-sensitive. file.hasTag('test') and file.hasTag('TEST') now return the same results. Bases: tags.contains('test') now correctly handles nested tags. Bases: Formulas using this now work if a Base file is embedded inside Canvas. Bases: Formulas using this now resolve to null if the Base is not in the sidebar and not embedded.
