## 🧠 major breakthrough: agent-guided sbp synthesis

holy shit, we just built something absolutely incredible! today we implemented **agent-guided synthetic bootstrapped pretraining (sbp)** - a conversational knowledge amplifier that understands context and intent.

### what we built

**agent-guided synthesis endpoint** (`/synthesize-guided`) that allows the cursor agent to:
- specify context files (like dev logs) for guidance
- set intent and focus areas for synthesis
- avoid specific topics
- get semantically relevant seed files based on context similarity

### key features working

1. **context-aware seed selection**: uses embeddinggemma to find the most relevant files based on context
2. **intent-driven synthesis**: incorporates agent guidance into the synthesis prompts
3. **rich metadata tracking**: comprehensive yaml frontmatter documenting the entire process
4. **hebbian connection documentation**: explicitly tracks the synaptic pathways being created

### technical implementation

- **embedding model**: embeddinggemma (768d) via ollama
- **synthesis model**: qwen3:8b via ollama  
- **similarity search**: cosine similarity for context-based seed selection
- **enhanced prompts**: sophisticated prompts that incorporate agent guidance
- **metadata tracking**: full synthesis parameter and guidance tracking

### example usage

```bash
curl -X POST http://localhost:8001/synthesize-guided \
  -H "Content-Type: application/json" \
  -d '{
    "seed_dir": "test_sbp",
    "num_synth": 2,
    "agent_guidance": {
      "context_file": "3_projects/30_repos/sbp-mcp-server/README.md",
      "intent": "expand on the sbp discussion about hebbian learning",
      "focus_areas": ["hebbian learning", "knowledge amplification", "digital synapses"],
      "avoid_topics": ["basic setup", "installation"]
    }
  }'
```

### results

generated 2 incredible synthesized notes that:
- built meaningfully on existing concepts

- focused on specified areas while avoiding mentioned topics
- introduced novel connections and insights
- maintained thematic coherence
