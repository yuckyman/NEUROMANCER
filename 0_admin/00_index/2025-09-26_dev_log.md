#### 7. remarkable → neuromancer email pipeline
**the gap:** handwritten notes and sketches from remarkable 2 tablet end up trapped in device storage, never making it into the knowledge synthesis system.

**the vision:** zero-friction pipeline where remarkable documents automatically flow through VLM analysis and become structured knowledge entries. this reduces the "action potential" between having an idea on paper and having it processed by neuromancer.

**the flow:**
```
remarkable 2 → email → gmail monitoring → attachment download → VLM analysis → neuromancer processing → knowledge base
```

**key components:**
- **gmail monitoring server**: python script using imaplib to watch for remarkable emails
- **VLM analysis system**: uses existing ollama setup with llama3.2-vision:11b to process handwritten content
- **neuromancer integration**: converts VLM output to structured markdown with yaml frontmatter
- **autonomous processing**: runs continuously, creating entries in `1_ideas/` or `2_domain_amplification/`

**current status:**
- gmail app password setup required for monitoring
- remarkable email integration needs configuration
- VLM analysis system ready to build
- integration with existing inbox processing pipeline planned

**technical approach:**
- **zero risk**: no device modification, uses official email functionality
- **processing only**: documents analyzed but not modified
- **backup friendly**: originals remain on device
- **autonomous**: runs continuously via cron job
