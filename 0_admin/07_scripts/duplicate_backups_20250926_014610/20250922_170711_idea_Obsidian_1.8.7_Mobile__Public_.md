Includes all new functionality and bug fixes up to Obsidian Desktop v1.8.7. No longer broken Android: The onboarding flow now has the option to use an existing folder as a vault. Fixed File Recovery and Sync crashing when iOS was in Lockdown Mode. &quot;Toggle left sidebar&quot; and &quot;Toggle right sidebar&quot; commands now work on phones. Fixed regression with sidebar pinning not being available on tablet devices. Fixed bug where pressing and holding on results in Global Search and Backlinks did not show the menu.
