Includes all new functionality and bug fixes up to Obsidian Desktop v1.9.8. Improvements Canvas: Added 'Duplicate' option to the node context menu. Swipe down on notices to dismiss them. No longer broken The &quot;Find...&quot; search input now immediately receives keyboard focus. Pressing &quot;return&quot; on your keyboard now dismisses the keyboard. &quot;Split down&quot; and &quot;Split right&quot; no longer appear in the context menu for the sidebar tabs. Fixed appearance of sidebar if you close all tabs.
