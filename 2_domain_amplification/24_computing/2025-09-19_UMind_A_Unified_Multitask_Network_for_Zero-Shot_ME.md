# UMind: A Unified Multitask Network for Zero-Shot M/EEG Visual Decoding

## summary
UMind is a new approach that combines visual stimulus retrieval, classification, and reconstruction from time-resolved brain recordings. It uses multimodal alignment to learn robust neural-visual and semantic representations through both image and text modalities.
