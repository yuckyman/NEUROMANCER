# Obsidian 1.9.6 Desktop (Early access)

## summary
Obsidian 1.9.6 introduces several updates, including improved formula validation, layout changes, and formatting improvements.

## content
RSS Feed: Obsidian Changelog
Source: https://obsidian.md/changelog.xml

Obsidian 1.9.6 Desktop (Early access)

No longer broken Bases: Fixed comparisons between dates and strings (e.g. date &gt; &quot;2025-07-18&quot;). Bases: Fixed logical operators in formulas not working (a &amp;&amp; b). Bases: Improved detection of invalid formulas. Bases: Fixed query builder in filters menu not always updating the operator correctly. Bases: Improved layout of formula editor. Increased the initial height, and added a status indicator showing when the formula is invalid. Bases: Fixed link() not working if URL has spaces. Bases: The properties menu now filters according to the display name and the property name. Bases: Fixed &quot;Image property&quot; sometimes not showing the selected value. Bases: Fixed Cards view setting incorrect scroll position when navigating back in history. Bases: Fixed filter menu showing the wrong input type when the selected property contains spaces.
