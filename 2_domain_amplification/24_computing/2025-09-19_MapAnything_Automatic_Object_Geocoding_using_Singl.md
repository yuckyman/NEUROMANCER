# MapAnything: Automatic Object Geocoding using Single Street-View Images

## summary
MapAnything is a module that automatically determines the geocoordinates of objects using individual images. It utilizes advanced Metric Depth Estimation models to calculate the object's distance from the camera, geometric principles, and camera specifications. The paper provides validation and recommendations for automating urban object and incident mapping.
