- [X] **coinbase** (easiest fiat on-ramp)

  - enable instant buy ($1000 limit initially)
  - buy initial sol (~$150 worth)
  
- [ ] **kraken** (backup exchange, better fees)
  - verify identity 
  - add bank account
  - set up as backup sol source

### solana wallet setup
- [ ] **phantom wallet** (browser extension)
  - install chrome extension
  - create new wallet (SAVE SEED PHRASE SOMEWHERE SAFE)
  - transfer sol from coinbase to phantom
  - test small transaction first ($10)

- [ ] **backup wallet security**
  - write seed phrases on paper (not digital)
  - store in fire-safe location
  - consider steel backup for paranoia level security

## 🚨 security checklist

### wallet security
- [ ] **seed phrase storage**
  - written on paper, stored offline
  - never photographed or digitally stored
  - consider splitting across multiple locations

- [ ] **device security**
  - updated browser and extensions
  - malware scan on development machine
  - separate browser profile for crypto stuff

### api security
- [ ] **api key management**
  - never commit api keys to git
  - use environment variables
  - rotate keys periodically

- [ ] **access controls**
  - enable 2fa on all accounts
  - unique passwords for everything
  - password manager (1password, bitwarden)
