   - Checkbox functionality for checkboxes
   - Image rendering inline without the need to use HTML

2. Changes to view formats:
   - View preview now shows only when interacting with context menus, not inside it
   - Fixed issues with image properties not working in certain file paths
   - Added new "Export CSV" feature

3. Improvements to page previews and filter menu:
   - Scrollbars are added if there is insufficient space on the screen
   - Cards view now scrolls when there isn't enough room

4. Bug fixes:
   - Fixed a bug where &quot;Export PDF&quot; only displayed the first page of images
   - Ensured that Image property works correctly even if file paths contain special characters

5. Minor improvements to context menus and filters:
