Shiny new things Bases has a new formula editor. It includes syntax highlighting, autocomplete, and shows documentation about the current expression. Improvements The &quot;Download attachments for current file&quot; command now downloads attachments from file properties in addition to the note body. Canvas: It's now possible to select a specific view for an embedded Base. Right-click and select &quot;Pin view...&quot; Improved how the Markdown parser handles large tables and large callouts. These notes will take slightly longer to load, but then the tables and callouts will be rendered instantly. Bases Bases now remember your scroll position when navigating forward and backward in history. Cards view can now display cards with no properties. Useful if you only want a cover image displayed. Formula properties and file properties now display dates and datetimes according to your OS locale.
