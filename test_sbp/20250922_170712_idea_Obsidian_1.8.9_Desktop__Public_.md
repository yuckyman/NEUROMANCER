1. Updated app performance for large number of items displayed in a tree view.
2. Improved app settings reflecting changes to the Commercial license.
3. List auto-numbering preserving custom starting numbers.
4. When Smart indent lists is disabled, editor no longer automatically renumbers lists.
5. Obsidian Sync: Added a warning before connecting to a remote vault if it's already managed by a third-party service that could cause conflicts.
6. Fixed regression causing large vaults to take significantly longer to load and save the cache (bug since Electron 33).
7. Live preview now correctly renders - - - as a horizontal rule.
8. Notes with corrupted fold information can be opened.
9. Tables inside embeds will now render full width.
10. Checklist items inside loose lists are indented correctly.
11. Clicking inside a PDF view now focuses the view.

The article highlights these improvements to enhance Obsidian's functionality and user experience.'
