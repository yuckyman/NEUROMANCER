summary: 'The article describes several updates and improvements in Obsidian Desktop v1.9.0:

1. **Resizing when keyboard appears and disappears**: The app now smoothly resizes when the on-screen keyboard appears and disappears.

2. **Improved navigation functionality**: Two-finger swipe to navigate forward and backwards in tab history is more responsive.

3. **Updated default layout for navigation bar**: The default layout for the navigation bar has been updated.

4. **Better adaptation to landscape mode**: The app now better adapts to landscape mode.

5. **Resetting password from initial onboarding flow**: It's possible to reset your Obsidian account password from the initial onboarding flow.

6. **Opening file context menu by pressing and holding on the file name in the Search view**: You can now open the file context menu by pressing and holding on the file name in the Search view.

7. **Collapsing sidebar after opening a file from the file explorer**: The sidebar collapses after opening a file from the file explorer.

8. **Pinning sidebars to tablets**: Ensure that popovers appear within the device insets, avoiding OS elements such as the Dynamic Island and navigation bar.

9. **Ctrl-Tab and Shift-Ctrl-Tab for switching between tabs on iPad**: Added Ctrl-Tab and Shift-Ctrl-Tab shortcuts for switching between tabs on iPad.

10. **Fixed layout issues with sidebars pinned to tablets**: Minor fixes were made to ensure that popovers appear within the device insets, avoiding OS elements such as the Dynamic Island and navigation bar.'
