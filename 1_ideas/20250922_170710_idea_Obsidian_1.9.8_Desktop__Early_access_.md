   - A new option called "New base" which allows users to add a new base or create a new one.

5. Changes made to the way files are displayed and navigated through, including:

   - When the view is active (File Explorer), holding Command/Ctrl while navigating through files using the arrow keys will open the file under the cursor.

In the filter menu, &quot;exists&quot; is no longer a valid operator. This was returning incomplete and incorrect results. Instead of &quot;&lt;property&gt; exists&quot;, you will need to update your filters to say &quot;file has property &lt;property&gt;&quot;. Bases: &quot;Tags&quot; and &quot;File tags&quot; are now hidden from the filter menu. Prefer to use &quot;file has tag &quot; instead. Bases: Added String#reverse and String#repeat functions.
